## How to Run & Compile (For Developers)

### 1. Extract the 3D Models
To keep the repository light, 3D assets are stored in a separate zip file.
1. Download the `models.zip` file.
2. Extract its contents.
3. Open the folder and follow the instructions inside the `readme.md` to place the assets in the correct project directory (root).

### 2. Open in Godot Engine
1. Download and install **Godot Engine** (make sure to use the version corresponding to this project, which is the 4.6 STABLE).
2. Open Godot, click on **Import**, and select the `project.godot` file at the root of this repository.
3. Press **F5** to run and test the game!

### 3. Compile / Export the Game
1. Go to **Project > Export** in the Godot menu.
2. Select or add your target platform (Windows, macOS, Linux).
3. Click on **Export Project** to generate your standalone playable build!
